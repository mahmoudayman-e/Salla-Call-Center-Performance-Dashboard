# Salla Call Center Performance Dashboard

## Overview
This project is an interactive Power BI dashboard developed to analyze the performance of a call center using operational KPIs and interactive visualizations.

## Objectives
- Monitor call center performance.
- Evaluate agent productivity.
- Analyze Service Level, ASA, Handling Ratio, and Abandonment Rate.
- Build a What-If Analysis to simulate call volume changes.
- Estimate required staffing based on expected call growth.

## Dashboard Pages
### Executive Dashboard
- Total Calls
- Handling Ratio
- Service Level
- ASA
- Abandonment Rate
- Call Trends
- Top Agents

### Operation Analysis
- Project Performance
- Monthly Analysis
- Service Level by Project
- ASA by Project
- Abandonment Rate by Project

### Agent Performance
- Agent KPIs
- Calls Handled
- ASA by Agent
- Handling Rate
- Abandonment Rate

### What-If Analysis
Users can simulate increases in call volume to estimate:
- Expected Calls
- Projected Handling Rate
- Projected Service Level
- Required Agents
- Additional Agents Needed

## Tools
- Power BI
- Power Query
- DAX
- Data Modeling

## Key KPIs
- Total Calls
- Handling Ratio
- Service Level
- Average Speed of Answer (ASA)
- Abandonment Rate
